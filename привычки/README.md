# Привычки

Трекер привычек: отмечаете галочками, что выполнили за день, и смотрите
процент выполнения плана за месяц. Приложение рассчитано на долгое
использование с произвольным набором привычек — не только с теми, что
заданы по умолчанию.

Открыть `index.html` в браузере — сборка не нужна. Все данные хранятся
в localStorage браузера; во вкладке «Привычки» есть экспорт/импорт JSON
для резервной копии.

## Модель данных

- **Привычка** — название, категория и один или несколько **периодов**
  частоты (сколько раз в день, по каким дням недели, с какой даты по
  какую). Периоды позволяют заранее планировать изменение частоты
  привычки (например, сейчас 1 раз в день, а с такого-то числа — иначе),
  не теряя историю выполнения за прошлые периоды.
- Повторения за день можно оставить пронумерованными (1, 2, 3, ...) или
  задать именованными метками (например, «Утро», «Вечер», «Ночь»).
- Привычку можно архивировать (скрыть из «Сегодня», но сохранить в
  статистике) или удалить вместе с историей.

## Вкладки

- **Сегодня** — чек-лист привычек, запланированных на сегодня, с
  процентом выполнения дня.
- **Привычки** — создание, редактирование, планирование новых периодов
  частоты, архивация/удаление, резервное копирование.
- **Статистика** — выбор месяца, общий % выполнения плана, разбивка по
  дням и по привычкам.

## Стартовый набор

При первом запуске добавлены привычки: упражнения для глаз (3×/день),
медитация утром/вечером/перед сном (3 отдельные привычки по 1×/день),
физупражнения (1×/день) и здоровое питание (1×/день, критерии можно
уточнить позже в поле «Заметки» при редактировании). Их можно свободно
менять, архивировать или удалять — это лишь отправная точка.
