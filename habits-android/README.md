# Привычки — Android

Обёртка веб-версии трекера привычек (`../привычки/`) в нативное Android-приложение.
Внутри — `WebView`, который открывает те же `index.html`/`style.css`/`app.js`
(лежат в `app/src/main/assets/`), плюс небольшой Kotlin-мост
(`MainActivity.kt`) для экспорта/импорта резервных копий через системные
диалоги выбора файла — на кнопки «Экспорт»/«Импорт» это не влияет, они просто
работают по-другому под капотом, чем в браузере.

Логика приложения (привычки, периоды частоты, статистика) не дублируется —
это тот же код, что в веб-версии. Если меняете `привычки/app.js` — не
забудьте скопировать файл заново в `app/src/main/assets/app.js` (или
пересобрать из корня скриптом ниже).

## Получить APK без установки чего-либо

В репозитории настроен GitHub Actions (`.github/workflows/build-android-apk.yml`):
при каждом пуше в `habits-android/**` собирается debug-APK. Чтобы скачать:

1. Откройте вкладку **Actions** репозитория на GitHub.
2. Зайдите в последний зелёный запуск **Build Android APK**.
3. Внизу страницы в разделе **Artifacts** скачайте `privychki-debug-apk`.
4. Перенесите `.apk` на телефон и установите (Android спросит разрешение на
   установку «из неизвестных источников» — это нормально для debug-сборки).

Можно также запустить сборку вручную без нового коммита — на вкладке Actions
у workflow есть кнопка **Run workflow**.

## Сборка через Android Studio

1. **File → New → Project from Version Control**, вставить URL репозитория.
2. Открыть именно папку `habits-android/` как проект (не корень репозитория).
3. Дождаться синхронизации Gradle (SDK подтянется автоматически).
4. **Run ▶** (с телефоном по USB с включённой отладкой, или эмулятором) —
   либо **Build → Build Bundle(s)/APK(s) → Build APK(s)** для файла `.apk`.

## Сборка вручную из терминала

Требуется установленный Android SDK (`ANDROID_HOME`/`local.properties`).

```bash
./gradlew assembleDebug
# файл появится в app/build/outputs/apk/debug/app-debug.apk
```

## Структура

- `app/src/main/assets/` — веб-приложение (копия `привычки/`).
- `app/src/main/java/com/habits/privychki/MainActivity.kt` — WebView +
  мост `AndroidBridge` для экспорта/импорта JSON через Storage Access
  Framework (без него в WebView не работают ни скачивание файла, ни
  `<input type="file">`).
- `minSdk 26` (Android 8.0+), без интернет-разрешения — приложение полностью
  офлайновое, данные хранятся в собственном хранилище WebView на устройстве.
